# CasaDesk

A subdivision helpdesk web application prototype designed for residents to report issues, pay fees, and view community announcements. 

## Features
- **Dashboard:** Overview of account balance and quick actions.
- **Ticketing System:** Form to report maintenance or security issues.

## Tech Stack
- HTML5
- CSS3 (Flexbox for layout)
- Vanilla JavaScript (for prototype page routing)
- Figma (for final UI mockups)

## How to Run the Prototype Locally
1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file to open it in your default web browser.
4. Click the navigation links to test the page transitions.

## Figma Integration
This codebase is optimized to be imported directly into Figma using HTML-to-Figma plugins. It uses semantic tags, zero emojis (SVGs/text only), and strictly relies on Flexbox to ensure clean auto-layout translation.
